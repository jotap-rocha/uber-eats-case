# Templates PowerPoint — Icatu

Arquivos de referência **oficial** para paleta, tipografia, capas e layouts corporativos.

| Arquivo | Uso |
|---------|-----|
| `template_ppt_Icatu.pdf` | Guia de marca do template (cores Pantone/RGB/HEX, Roboto, tipos de slide). |
| `ppt_trilha_de_auditoria_jan_2026.pdf` | Exemplo de deck aplicado (estrutura de conteúdo e ritmo visual). |

## Logo

A logomarca **oficial** deve ser obtida na **Vitrine de Marketing** / **Guia da Marca** (Portal Corporativo), conforme o próprio template PDF.

Coloque exportações autorizadas nesta pasta, por exemplo:

- `assets/logo-icatu-horizontal.svg` (ou `.png` em alta resolução)
- `assets/logo-icatu-vertical.svg` (se aplicável)

Não recrie o logo em vetor “de memória”: use apenas arquivos **aprovados** pelo time de marca.
