# Menos é mais (progressive disclosure)

> **Purpose**: Mostrar o essencial primeiro; detalhes sob demanda.  
> **Confidence**: 0.93

## Regra de ouro

**Tela principal para decisão. Tela de detalhe para investigação.**

## O que vai onde

| Camada | Conteúdo |
|--------|-----------|
| **Lista / dashboard** | KPIs, outliers, filas, próxima ação |
| **Detalhe** | Histórico completo, evidências, notas, metadados |
| **Logs técnicos** | Área separada, colapsada, ou rota `/debug` / drawer |

## Filtros

- Mostrar filtros “quentes” sempre; avançados atrás de “Mais filtros”.
- Não duplicar o mesmo filtro em dois lugares sem sincronização óbvia.

## Documentação inline

Tooltips curtos; links “Saiba mais” para políticas longas.

## Benefício

Reduz carga cognitiva para o analista que passa o dia inteiro na ferramenta.
