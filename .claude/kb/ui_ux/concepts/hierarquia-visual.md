# Hierarquia visual

> **Purpose**: Guiar o olhar: o mais importante primeiro, sem gritaria visual.  
> **Confidence**: 0.92

## Como construir

| Camada | Exemplo |
|--------|---------|
| **Primária** | Título da página, KPI principal, botão de ação principal |
| **Secundária** | Filtros, tabs, ações secundárias |
| **Terciária** | Metadados, timestamps, links “ver mais” |

## Técnicas

- **Contraste tipográfico**: escala limitada (ex.: 2–3 tamanhos + peso).
- **Espaço em branco**: agrupa relacionados; separa blocos decisão × exploração.
- **Cor como realce**, não como decoração — Reserve saturados para alertas e CTAs.
- **Alinhamento em grade**: grids consistentes evitam “sensação de protótipo”.

## Acessibilidade

Hierarquia não pode depender só de tamanho/cor: estruture headings (`h1` → `h2`) de forma lógica para leitores de tela.
